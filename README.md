# Running Man Game

This repository contains a simple browser game where a running man avoids obstacles. Click or press the spacebar to make the player jump over incoming obstacles.

## How to Play

1. Open `index.html` in a modern web browser.
2. Click anywhere on the page or press the **Space** key to make the player jump.
3. Avoid the obstacles for as long as possible. If you collide with one, the game is over.

Enjoy!
